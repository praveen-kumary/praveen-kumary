### 🧑‍💻 About Me

Full-Stack Engineer building robust web applications, data pipelines, and open-source software.  
I specialize in **TypeScript**, **Next.js**, **Node.js**, and **Python** backend systems — and I ship production code to real users every week.

- 🔭 Currently building **[MotoTribe](https://github.com/praveen-kumary/mototribe)** — a motorcycle community & multi-seller marketplace
- 🌱 Contributing to major open-source projects including **Next.js**, **Astro**, **Hono**, **Zod**, and **Drizzle ORM**
- 🏥 Active contributor to **[HMIS](https://github.com/hmislk/hmis)** — Hospital Management Information System (Jakarta EE)
- 📅 Core contributor to **[Cal.diy](https://github.com/praveen-kumary/cal.diy)** — scheduling infrastructure by Cal.com
- ⚡ Fun fact: I've contributed to **7+ major open-source repositories** across different ecosystems
